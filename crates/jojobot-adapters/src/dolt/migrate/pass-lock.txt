# The one-time store passes, each with a hash of the code that drives it.
#
# A pass is marked finished in `store_pass` under its name. A store where the old
# code already finished holds that name, so changed code under the same name
# never runs there. The test in lints.rs recomputes each hash from the source and
# compares it with this file.
#
# When a pass's code changes, give the pass a new name. If running it again is
# unnecessary, update the line here and say why in the commit.
#
# The hash covers the function that drives the pass, read with comments and
# spacing outside literals left out. It does not cover the helpers that function
# calls. A pass is declared as `const NAME_PASS: &str` or named in a `PASSES`
# array; the four permanent-id passes share the one function that runs them, so
# they share a hash.
#
# Format: CONSTANT | the name stores record | hash of the driving function
