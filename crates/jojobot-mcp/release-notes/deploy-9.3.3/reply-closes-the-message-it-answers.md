## What you can now do

The instructions and mail descriptions name both ways to close mail: `mark_processed` and a reply with `in_reply_to`. A reply closes the message it answers when that message is in your own box.

## Example

Marge has started Bart's dispatch and still owes its tests. Marge posts the progress report without `in_reply_to`, so the dispatch stays open. After finishing, Marge replies with `in_reply_to` naming that dispatch, and the reply closes it.

## What to do

Send a progress note or partial report without `in_reply_to` while work remains. Close mail only after acting on it.
