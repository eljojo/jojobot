for: roles that tidy long claims, and roles that stopped editing one after a size refusal
reach_for_it_when: an edit to a claim is refused as too big to read back whole, though the edit makes it smaller
miss: A bot that gave up on shortening a long claim because every edit was refused can now shorten it.

## What you can now do

`update_fact` refuses an edit that would grow a claim past what one answer can read back whole, and leaves the claim unchanged. An edit that does not grow it is allowed, so a claim that is already too big can be shortened.

## Example

A claim on `person:ralph` is already too long to read back whole. An edit that cuts a paragraph lands. An edit that adds words is refused.

## What to do

To bring a long claim back within reach, edit it down. To add to it, split the text into claims that each say one thing, or keep the long text on a document and write a pointer claim.
