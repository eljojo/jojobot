# Finding your way — the surface teaches itself

> **jojobot** · kind: feature-brief · boot: on-demand · verified: 2026-09-03

**An agent that has never met jojobot can reach what it needs without already knowing the thing exists.** Every answer, every refusal and every description points at the next move. **The surface is not documented; it teaches.**

## Why this is a feature and not a writing habit

**jojobot exists to hold the method so an agent does not have to.** A kind carries its own contract, so the loop's arithmetic, the entitlement's window and the claim's provenance are the software's job rather than something a session works out again each time.

🚨 **A contract an agent cannot discover is a contract it re-derives.** And re-deriving is the exact cost this product exists to remove, so a capability nobody can find is worse than one that was never built — it was paid for twice and it returns nothing.

⭐ **The failure this closes is the loudest one in the record, and it is not a storage failure.** Something is captured correctly, sits where it belongs, and is never read — because the session that needed it did not know to ask.

## One door, and nothing is pushed

**There is a single place to arrive.** It orients, it says what exists right now, and it names the procedures the build ships without shipping their bodies.

**A procedure arrives when it is asked for by name.** Pushing all of them spends a session's attention on the ones it does not need, which is the same waste as an answer that dumps.

**The index says what each is FOR and never when it applies.** Deciding that is the agent's, and a door that decides it is a door that is wrong at the edges.

## A teaching arrives the first time it is needed, once

**Some conventions have to be known before a caller writes, and telling it to fetch a procedure first does not work** — a session that does not know a convention exists does not know to go and read about it.

**So the teaching rides the call where the subject is first touched, once, and jojobot knows whether that session has had it.** Not a footer on every read, which teaches a caller to skip it. Not at the door either, where it arrives before the session has anything to attach it to.

⭐ **It states the convention rather than listing key names**, so a shape added later is already covered by the sentence that is there.

⚠️ **A teaching that names a route the engine refuses is worse than no teaching**, because the caller follows it, gets refused, and reaches for whatever the refusal leaves open. **What is taught and what is accepted are one thing, and they are checked together.**

## A refusal is a signpost

**A misuse comes back blocked with a way forward, never a bare error.** It names what was wrong and what to do instead — the values a key accepts, the argument that was needed, the verb that does what was wanted.

⭐ **This is the highest-traffic teaching surface there is**, because a caller reads a refusal at exactly the moment it is trying to do the thing. A bare rejection on a path an agent uses constantly costs more than the defect it reports.

⚠️ **A refusal that offers a way through must actually have one.** Advice pointing at an override that does not lift the gate sends a caller round a loop for ever, and it reads as help.

## An answer says what it left out

**A small answer names what it held back, and the call that returns it.** That is what separates a small answer from a lossy one, and it is why nothing has to be shipped by default just in case.

**Anything already delivered comes back marked**, with its size in place of its body, so a caller can tell a leftover from something new without paying twice.

## Knowledge is fronted rather than waited for

**An answer carries what the caller did not ask about but is about to need.** Posting a message hands back the mail waiting in your own box, in the same call. A read about a person carries what that person holds, ranked, without anybody asking.

⭐ **This is the mechanism that beats a better manual.** A read somebody has to remember to issue is a read that will not be issued at the moment it mattered.

⚠️ **It is bounded, ranked and honest about the ranking.** A budget filled greedily by a bad order is a dump with a limit.

## Verbs that admit what they are for

**Two ways to find something, and each says which to reach for.** One starts from a subject you already hold and walks out from it. One is breadth, for when you do not know where to look.

**The surface grows by packing more into what exists, not by adding another verb.** A caller that has learned one verb should find the new capability as an argument on it.

## The test

**Could an agent that has never seen this reach it from where it is standing?**

**Two halves answer that, and neither substitutes for the other.** Reading the surface says whether a path exists. **A real model meeting the surface cold says whether the path is taken** — and only the second one can fail in the way that matters.

## What it is not

**Not a manual.** Nobody reads one, and a manual that goes stale is worse than none because it is believed.

**Not prose in a tool description that sells the tool.** A description says what the verb does, what it refuses, and what to reach for instead. Enthusiasm is not information.

**Not pushing everything.** Fronting what a caller is about to need is the feature; shipping everything is the failure it exists to avoid.

**Not a promise that the storage product is discoverable.** An agent may know how jojobot is *arranged* — that things nest, that kinds carry keys, that claims draw edges. It is never handed anything true only of where the bytes live.

**Not a substitute for the shipped charter.** A charter says what an identity is for. This says how to work the surface. An agent that has to be told its job in a tool description has a charter problem.
