# The status bar — telling a caller what it did not ask about

> **jojobot** · kind: feature-brief · boot: on-demand · verified: 2026-09-03

**Every answer carries one small uniform block for what the caller should know and did not ask.** The pattern is to front knowledge to the agent and spend fewer calls doing it.

## One entrant

**Waiting mail, and only when there is some.** The block is silent at zero.

**A second entrant earns its place on evidence, one at a time.** "Information when relevant" is an open slot, and a growing list of things to report is the tell that a principle got built as an enumeration.

## Uniform across every verb

**The same block, in the same place, on every answer the surface returns.** A bar that appears on some verbs and not others has to be learned per verb, which is the opposite of fronting knowledge.

## Why it exists

**The failure it is aimed at is not an agent that goes quiet.** It is two agents corresponding — each one sending, each one holding a reply it has not seen, neither blocked, both proceeding on a picture the other has already corrected.

**An instruction to check your mailbox does not fix that**, because the moment an agent most needs to check is the moment it is least likely to think of it. Fronting the count removes the need to think of it at all. This class of failure gets a mechanism, never more prose.

## What it never carries

**Never how jojobot established anything.** A caller learns what is true for it — that mail is waiting, that a write landed. The checks the server ran on itself are not a caller's business, and an agent told about a guard starts reasoning about the guard instead of the answer.

⚠️ **So a box jojobot cannot read produces NO block, rather than a block describing the trouble — and silence here is therefore never a claim that the box is empty.** Nothing is the only honest thing an unsolicited block can say about a question nobody asked. **The verbs that answer FOR mail report an unreadable box, because there a caller did ask.**

**Never a word that means two things.** "Verified" carries only that bytes persisted, and it reads as though a claim were true — one word doing duty for two checks, in a system whose named failure is fabrication.

## What it is not

**Not a notification system.** Nothing is pushed, nothing interrupts, and nothing arrives outside an answer the caller already asked for.

**Not a nag.** It states a count. What to do about it is the reader's.
