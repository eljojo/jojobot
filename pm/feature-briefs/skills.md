# Skills — the method, fetched when it applies

> **jojobot** · kind: feature-brief · boot: on-demand · verified: 2026-09-03

**A skill is a procedure: what to do when a particular kind of job is in front of you.** Skills are how the method ships with the software rather than being configured onto it.

## Composable documents, not one block of prose

**Each skill is its own document with its own instructions.** They compose into an order rather than presenting a menu, and they read as how the work is done rather than as suggestions.

**A skill is prose and it adds nothing to the surface.** It tells a mind how to work the verbs that are already there, which is why a new one costs a caller nothing until the caller asks for it by name.

## Fetched, never pushed

**A boot carries an index — every skill's name and what it is for — and no bodies.** One body is fetched by name, through the same door the boot came through, because that door is skill zero: it is where a session learns the model, so it is where a session learns the procedures.

**Nothing is loaded speculatively.** An orientation that hands over every procedure in case one applies pays for all of them on every boot.

## The trigger is invoked, never inferred

**A session reads the index and decides.** jojobot deciding when a skill applies would be inference, and jojobot performs none.

⚠️ **A skill's when-to-use has to name something the session can actually observe about its own situation.** One that names a state the session cannot see — a condition somewhere else in the system — will not be reached at the moment it matters, however well it is written.

## A skill is not a charter

**A skill is a procedure, fetched when the index says it is relevant. A charter is standing behaviour — what a bot is, always, before anything is fetched.**

Collapsing them would put always-on text behind an on-demand fetch, which is how a bot ends up not knowing what it is for.

## What it is not

**Not configuration.** An instance does not assemble a method from parts; it receives one and adjusts it.

**Not a rulebook the software enforces.** A skill informs a mind that is free to judge; nothing checks that it was followed.
