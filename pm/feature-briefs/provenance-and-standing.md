# Provenance and standing — who backs a claim, and how sure

> **jojobot** · kind: feature-brief · boot: on-demand · verified: 2026-09-21

**Every claim answers two questions, and they are independent.** Who backs this, and how sure is it. One field each, because collapsing them makes a confident guess indistinguishable from a settled fact.

## The two axes

* **Provenance** — **testimony**, the operator said or confirmed it · **observation**, an agent read it in a system of record and named which one · or **inference**, an agent derived it.
* **Standing** — **settled** or **open**.

**All four pairings are legal, and that is the point rather than a permissiveness.** Something the operator said while thinking aloud is testimony and open: really theirs, and not decided.

## Inference is the default

**A derived claim reads back as a hypothesis, never as truth.** Only the operator's explicit confirmation promotes it.

This is the whole defence against the failure the project is named after. **An unmarked guess loads on the next boot carrying the authority of something that was said** — and nothing downstream can tell the difference, because the marking is the only difference there ever was.

**Promotion carries a receipt:** what was checked, in enough detail that somebody else can run the check again. A claim a machine can settle for itself — whether a folder exists — is settled that way and says how. **Two things count as a receipt, and they are told apart: a check that ran, or the operator's own explicit confirmation.** ⭐ **Promotion moves standing and never provenance** — a promoted inference still reads as an inference, because that label is what makes the next reader careful.

## A value nobody declared is not a value

**Standing that nobody asserted is stored as nothing**, and a reader derives what the provenance implies.

Writing in the value that provenance suggests would be the same defect one level down: a field that reads as somebody's judgement when it is a default. **The absence is information and it is kept.**

## Fixing a claim

**Which shape a correction takes depends on who wrote the claim.** A claim the current session wrote is rewritten in place. A claim an earlier session wrote is archived, and the corrected claim stands beside it, so the correction stays visible — somebody may already have read the old one. **The session boundary is the axis because it is the one signal an agent actually has.**

**Either shape, new words need a new answer to the first question.** ⭐ **Replacing what a claim says while leaving its provenance alone lets a record go on naming the operator as the source of words they never said** — so a rewrite that changes the content and states no provenance is refused, and the refusal says what to supply. ⛔️ **Never a silent demotion.** Somebody fixing a typo in their own testimony should not find it quietly downgraded, and the caller is the one who knows how they know.

**Nothing stores a sentence saying what a thing is not.** A negative about the world is an ordinary claim — *Milhouse did not attend* — and a negative is never the shape a correction takes.

**An archived claim keeps its provenance and every wording it has been through stays readable.** A reader can tell *never recorded* from *recorded and wrong*. That is what makes an agent willing to correct a record rather than write a second one beside it: correcting costs nothing, because what it used to say is reachable rather than gone. There is no deletion, because a delete is a write.

## What it is not

**Not a confidence score.** jojobot performs no inference, so a number would be a model's self-report wearing the authority of a measurement.

**Not a denylist of things that turned out wrong.** A bad claim is fixed at the question that produced it; a list of wrong answers re-embeds every name it forbids.

**Not a guess about which claims look suspicious.** These fields record what is true about a claim, and the only write they refuse is the one that leaves the first question unanswered when the answer has changed. **A guard deciding for itself what needed checking would be a different and worse thing.**

**And what a derived answer carries.** A claim answers both questions, and so do two of the things built on it. **A folded value names the claim whose write won it, with that claim's own provenance and standing.** **The block naming who is admitted to something carries them too.** ⭐ **So the shape a value assembled from three claims arrives in is no longer indistinguishable from something the operator said this morning.**

⚠️ **A COUNT AND A TYPE MATCH STILL ANSWER NEITHER, and that is the residue.** **A total is arithmetic over writes rather than one winning claim, so there is no single provenance to carry** — and what a reader should be told instead is not settled here.

⛔️ **Nothing about this is free by default.** **The backing is a second read and it is off unless a caller asks**, because a value arriving with its whole lineage on every read is a firehose. **The answer says the backing exists and names the call that returns it — an omission a reader cannot see is the one they will get wrong.**
